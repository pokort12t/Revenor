Ravenor — Telegram Mini App

Файли:
- index.html — головна сторінка
- style.css — дизайн
- script.js — логіка
- images/map.png — сюди поклади свою карту Ravenor

Для GitHub Pages завантаж усі ці файли зі збереженням структури папок.

ВАЖЛИВО:
Ця версія є frontend-прототипом. localStorage не створює справжній спільний сервер на 55 гравців.
Для реального мультиплеєра пізніше потрібні backend і база даних.

Telegram Mini App:
після публікації GitHub Pages URL можна буде підключити до Telegram-бота через BotFather.
