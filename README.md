# Ravenor
MVP Telegram Mini App / Flask + SQLite.

## Запуск
python -m pip install -r requirements.txt
python app.py
Потім відкрий http://127.0.0.1:5000

У Mini App заміни dev-ідентифікатор на перевірку Telegram WebApp initData на сервері.

## Важливо
Це робочий фундамент, а не фінальна MMO: потрібні HTTPS, справжня Telegram авторизація, бойовий движок, синхронізація та твоя фінальна карта.
