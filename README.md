# 👑 Королі та Лорди

Telegram Mini App — прототип середньовічної стратегії українською мовою.

## Функції прототипу

- Карта з 51 регіоном
- Статуси: самостійний лорд і лорд-васал
- Золото, їжа та матеріали
- Столиця, міста, села, шахти й ферми
- Наймання солдатів, кінних воїнів, лицарів і лучників
- Покращення будівель, збір ресурсів і навчальний похід
- Збереження локального прогресу в браузері
- Адаптивний інтерфейс для телефону
- Підтримка Telegram Web Apps SDK

## Запуск через GitHub Pages

Цей прототип можна запустити як статичний сайт:

1. Створи новий репозиторій на GitHub.
2. Завантаж у репозиторій `index.html` та інші файли.
3. Відкрий **Settings → Pages**.
4. У розділі Build and deployment вибери **Deploy from a branch**.
5. Вибери гілку `main` і папку `/(root)`, потім натисни **Save**.
6. Дочекайся публікації сайту за адресою GitHub Pages.

`index.html` у корені потрібен для GitHub Pages. Папка `public/` містить копію цього файлу для запуску через Node.js/Express.

## Запуск сервера локально

Потрібен Node.js 20 або новіший:

```bash
npm install
npm start
```

Сервер буде слухати порт `3000`.

Щоб перевіряти Telegram `initData`, перед запуском задай змінну середовища `BOT_TOKEN` зі справжнім токеном свого Telegram-бота. **Не додавай токен у GitHub і не вставляй його в `index.html`.**

## Підключення до Telegram

1. Створи бота через офіційного `@BotFather`.
2. Розмісти вебзастосунок на HTTPS-хостингу.
3. У налаштуваннях бота задай URL Mini App.
4. Відкривай гру через кнопку бота в Telegram.

## Важливо: це прототип

GitHub Pages може розмістити лише фронтенд. У цій версії ігрові дані зберігаються в `localStorage` на пристрої гравця. Тому зміни не синхронізуються між різними гравцями, а політика й навчальний похід працюють як локальна демонстрація.

Для справжньої багатокористувацької гри необхідно додати бекенд і базу даних. Саме сервер має перевіряти золото, наймання військ, будівництво, битви, присяги та розподіл гравців по серверах — не можна довіряти цим діям лише браузеру.
