# Ravenor Mini App — v0.1

Перший робочий каркас гри для Telegram Mini App.

## Що вже є
- Telegram Mini App frontend.
- Backend на Node.js + Express.
- SQLite база.
- 20 серверів-заготовок.
- Ліміт 55 гравців у перевірці стану сервера.
- 55 регіонів.
- Назви всіх 55 регіонів.
- Регіони 3, 7, 8 — зимові.
- Гравець автоматично створюється як лорд.
- Стартовий регіон.
- Перегляд карти та регіону.
- Захоплення вільного сусіднього регіону.
- Базові ресурси: золото, їжа, залізо, дерево, камінь.
- Золото стартує з 1000 на гравця.

## Запуск
1. Встановити Node.js 20+.
2. Скопіювати `.env.example` у `.env`.
3. Вписати токен Telegram-бота у `BOT_TOKEN`.
4. `npm install`
5. `npm start`
6. Для реального Telegram Mini App сервер має бути доступний через HTTPS.
7. У BotFather налаштувати Mini App/Web App URL.

Для локальної розробки є dev fallback, але перед production його потрібно вимкнути.
